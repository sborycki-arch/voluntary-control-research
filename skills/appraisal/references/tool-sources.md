# Official appraisal tool sources (consult, do not reproduce)

- RoB 2 (randomised trials; crossover and cluster variants): https://www.riskofbias.info/welcome/rob-2-0-tool — record the template version date.
- ROBINS-I (non-randomised studies of interventions): https://www.riskofbias.info/welcome/home/current-version-of-robins-i — record the version (V2 if adopted).
- JBI critical appraisal checklists (case reports, case series, prevalence studies, quasi-experimental): https://jbi.global/critical-appraisal-tools
- GRADE: handbook at https://gdt.gradepro.org/app/handbook/handbook.html; the GRADE Book (online, ongoing revision) for current guidance; Summary of Findings table format from GRADEpro GDT.
- Minozzi et al. 2020, J Clin Epidemiol 126:37–44 (doi:10.1016/j.jclinepi.2020.06.015): human–human RoB 2 agreement benchmark (Fleiss' κ 0.16, 95% CI 0.08–0.24; four raters, 70 RCTs). Unverified: the primary was not opened from the build environment (R-036); cite only after it has been read. Cite when reporting agent-vs-human agreement.
