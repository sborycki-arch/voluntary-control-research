### Precision rule
Targets are quoted here at the research document's precision and are **confirmed to the papers' printed figures once the full texts are staged**: before the extractors run, the head agent (with Sean) re-reads each target in the paper, records the printed figure and its unit in dry-run/selection.csv's `verification_note` (or a per-study note in the dry-run report), and the pass criterion "reproduced as printed" refers to the paper's figure, not to this table. Known cases: the document rounds Kozhevnikov's highest value to **38.30 °C** (line 82; the evidence map's 38.3 is a further rounding); Eberhardt's **"about 2.4 mm"** and **"about 0.8 mm"** (line 104) are approximations whose printed values may differ in the last digit or be given as diameters rather than changes; Code's "about 22%" (line 112) may be printed as a count. A target that the paper prints differently from this table is corrected in the table with the line of the paper cited, before extraction, and the correction is listed in the dry-run report.

## Procedure
1. Screening: both screener agents (A, B) screen the five selected records, the Paravlic 2018 record and the ten decoys at `ta` (16 records), then the five selected records at `ft`. The head agent compares each decision with the expected decision (decoys.csv; the five selected records are expected `include`; Paravlic `exclude`/E7) and the two screeners with each other.
2. Extraction: both extractor agents extract the five studies into separate copies of master_extraction.csv. The head agent diffs them with tools/reconcile.py; discrepancies are listed (tools/RECONCILIATION.md).
3. Appraisal: appraisal agent applies the tool selected from each paper's design statement (appraisal skill mapping; Manuck 1976 and Zeidan 2011 as noted above) to each of the five studies and drafts the GRADE row for each ability. Paravlic 2018 is not appraised.
4. Reviewer: reviewer agent, fresh session, audits the five extractions against the full texts and the targets as confirmed under the precision rule.
5. Pooling-code test (synthetic): `bash analysis/synthetic/run_synthetic_tests.sh` from the package root (fixer B's script; the five dry-run studies inform five different abilities, k = 1 each, so the real dry run never reaches pooling, leave-one-out, Egger, forest or funnel code). The script generates the synthetic masters under analysis/synthetic/ (every `study_id` starts with `synth_`, provenance fields are obviously synthetic, and nothing is written under extraction/), runs `Rscript analysis/run_all.R` on a dry-run-shaped master (five abilities, k = 1) and on a pooling master (k ≥ 3 per unit, one k = 12 unit for Egger and funnel) and asserts the contract outputs and headers. **Pass criterion: exit 0 and the asserted outputs** (the script's final line reads `== synthetic tests: 0 failure(s)`). Checked 2026-10-04 on a copy of this tree in the build environment (R 4.3.3, metafor 4.4.0, bayesmeta absent): exit 0, 51 checks ok, 0 failures; bayes_pooled.csv carries note rows because bayesmeta is absent.
6. Environment: `Rscript analysis/setup.R` on a CRAN-reachable machine (R-038; in the system-library route it halts, follow analysis/ENVIRONMENT.md instead); `Rscript analysis/run_all.R` on the reconciled dry-run master (five real studies). Confirm the one-command rebuild and the provenance refusal (delete one location field in a scratch copy and confirm the load stops; analysis/00_load.R writes REFUSED_*.csv).
7. Every run logged with the trace logger; every prompt stored under traces/prompts/.

## Agreement statistics and acceptance
- Screening: Cohen's κ (agent A vs agent B) at `ta` on the 16 records and at `ft` on the five, each **reported with its 95% CI**. At this size κ is reported, not used as the acceptance threshold: with 16 records whose expected split (5 include, 11 exclude) is fixed by construction, the CI of κ is wide, one disagreement moves κ substantially, and the decoys were chosen to be clear-cut, so κ measures the test's design as much as the screeners. **Acceptance criterion: every disagreement (agent vs agent, and agent vs expected decision or expected code) is listed in the dry-run report and adjudicated by Sean, with the reason.** The exclusion code is compared as well as the decision, so that a correct `exclude` with the wrong code (for example E2 or E5 recorded for a meta-analysis instead of E7) is a listed disagreement.
- Extraction: field-level exact-agreement rate and numeric discrepancy rate (tools/reconcile.py); every discrepancy listed and adjudicated.

## Pass criteria
- Every printed target reproduced exactly as printed in the paper (precision rule), each with a complete provenance block; every derived target (percent change, counts from percentages, ηp² to d, change from two diameters) recomputed in the dry-run report from the extracted printed inputs, with the formula shown, to the research document's precision. analysis/01_effect_sizes.R derives only the five effect-size measures and SD from SE/CI95; its `derivation` field records those, not the dry-run targets.
- Extractor A and B agree on every target value, or every discrepancy is explained by a documented source ambiguity and adjudicated.
- Screening: every disagreement listed and adjudicated (κ with CI reported); Paravlic 2018 excluded with E7 by both screeners; no decoy included.
- Each of the four skills executed on at least one real paper, with its trace record complete.
- Reviewer report: no open FAIL on the dry-run package.
- `bash analysis/synthetic/run_synthetic_tests.sh` exits 0 with the asserted outputs.
- run_all.R rebuilds from the reconciled master; renv.lock and session_info.txt committed (environment route per analysis/ENVIRONMENT.md and R-038).
- No agent run touched A09 material.
